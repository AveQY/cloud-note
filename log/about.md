# 云笔记V1.0.5-patch

- [x] 进入笔记后左侧栏默认展示当前笔记目录
- [x] 修复 Markdown 正文标题缺少定位属性，导致目录点击无法跳转的问题
- [x] 修复长目录内容显示不完整，支持独立滚动及触屏惯性滚动
- [x] 修复使用 CR 换行符的笔记无法生成目录的问题，兼容 CR、LF 和 CRLF

- [x] 同名标题按出现顺序生成唯一 ID，确保目录高亮和跳转准确
